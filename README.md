- [Astro 6](https://astro.build/) — `output: 'static'` with one on-demand API route (`/api/brief`)
- [Tailwind CSS 4](https://tailwindcss.com/) — via the `@tailwindcss/vite` plugin
- [Resend](https://resend.com/) — transactional email for the quote brief
- Deployed on [Vercel](https://vercel.com/) (`@astrojs/vercel` adapter)
- **Bilingual** es/en (Spanish default), both URL-prefixed
